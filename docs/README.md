# CEC220 Logic Studio

This directory is a static GitHub Pages site. No build step or server-side
runtime is required.

## Structure

- `index.html` — course tool hub
- `arithmetic/` — Fixed-Width Arithmetic Workbench
- `fsm/` — State-Machine Design Workbench
- `algorithms/` — shift-and-add multiplication and non-restoring division
- `hamming/` — parity placement, syndrome correction, and code distance
- `shared/` — common styling and tested arithmetic logic
- `legacy/` — preserved standalone HTML tools
- `tests/` — Node-based exhaustive logic tests

The Colab notebooks in the repository root remain the readable Python
references for later tool conversions.
